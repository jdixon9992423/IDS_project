# Instrusion Detection System using Machine Learning


Multiple ML Models were trained on incoming packets for this project, an ensemble approach was used to detect malicious packets. The ML Models used included SVM, Decision Trees, Adaboost and Multi-Layer Perceptrons.


These ML Models were trained on 4 types of threats.
1. Exfiltration Detection
2. OSScan Detection
3. Keylogger Deetection
4. Service Scan Detection

Please see research Paper for summary.
